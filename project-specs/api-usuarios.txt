# Especificações das APIs

## Usuários

### Requisição

- Método: `GET`
- URL: `http://10.101.195.111:51080/api/btb/v1/usuarios`
- Autenticação: HTTP Basic Auth
- Corpo da requisição: não se aplica

> As credenciais de autenticação não devem ser armazenadas neste arquivo.

### Resposta observada

- Status HTTP: `200 OK`
- Content-Type: `application/json`
- `total`: quantidade de usuários retornada na resposta.
- `hasNext`: indica se existe uma próxima página de resultados.
- `items`: lista dos usuários.

Cada item de usuário possui os campos:

- `companyId` (string): identificador da empresa.
- `code` (string): código do usuário.
- `dialect` (string): idioma do usuário.
- `name` (string): nome do usuário.
- `_expandables` (array de strings): relacionamentos que podem ser expandidos.
- `email` (string): e-mail do usuário; pode ser vazio.
